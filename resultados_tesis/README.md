# Resultados seleccionados de la tesis

Selección automatizada de métricas y figuras ligeras desde los directorios de experimentos de Hypatia.
Consultar `inventario_resultados.csv` para los archivos originales, tamaño y hash parcial.

**No incluye** datasets, modelos entrenados, características Inception `.pt`, imágenes individuales, archivos ZIP ni mosaicos de vecinos cercanos que muestran fotografías de entrenamiento.

La selección es una ayuda para archivar los resultados, no sustituye la revisión científica. El KID entre diferentes datasets no constituye una comparación directa de calidad.

Los archivos grandes permanecen en Hypatia y no se borran.
